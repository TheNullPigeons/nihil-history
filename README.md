Standalone offensive engagement knowledge tool embedded in nihil containers. Tracks engagements, credentials, hosts, and access links across sessions.

Run `nhi tui` or `nhit` to open the interface below the command line, keeping terminal history visible. Run `nhitf`, or add `--full` (`nhi tui --full` or `nhit --full`), to use the full terminal screen.

Use `-h` or `--help` on `nhi` and its subcommands, or on `nhit` / `nhitf`. In the interface, `1`–`4` or `F1`–`F4` switch tabs and focus the table; up/down arrows and `j`/`k` focus the table and move between rows. Press `?` for all shortcuts.
